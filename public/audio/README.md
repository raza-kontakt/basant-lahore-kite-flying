# Background Music

To add background music to the game:

1. Place your music file here as `basant.mp3`
2. The file should be in MP3 format
3. If the file is not present, the game will run normally without music (no errors)

The music will:
- Auto-play when the game starts (after user interaction due to browser policies)
- Loop continuously
- Can be toggled on/off in Settings
- Volume can be adjusted in Settings

## Example file structure:
```
public/
  audio/
    basant.mp3  ← Your music file goes here
```
